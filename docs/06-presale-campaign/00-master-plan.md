## 二、产品矩阵与定价

### 2.1 4 档套餐设计

| 套餐 | 智能体 | 月租官价 | 老客户预售价 | 替代人力 | 月节省 |
|------|--------|---------|------------|---------|--------|
| 入门版 | 录入 | ¥1,000 | ¥800 | 1 名兼职录入员 ¥3-5K | ¥2,200-4,200 |
| 标准版 | 录入 + 库存风控 | ¥2,500 | ¥1,800 | 1 名仓管员 ¥5-8K | ¥3,200-6,200 |
| 专业版 | 录入 + 库存 + 出纳 | ¥4,000 | ¥2,800 | 1 财务 + 1 仓管 ¥12-18K | ¥9,200-15,200 |
| 旗舰版 | 全智能体 + 优先服务 + 数据看板 | ¥5,000 | ¥3,500 | 2-3 名管理 ¥20K+ | ¥16,500+ |

### 2.2 定价心理学设计

**为什么这样定价？**
1. 入门版 ¥800 → **降低决策门槛**，让客户先用起来
2. 标准版 ¥1,800 → **甜蜜点**（最容易出单的价位）
3. 专业版 ¥2,800 → **黄金套餐**（毛利最高 + 客户感知 ROI 最强）
4. 旗舰版 ¥3,500 → **锚点效应**（让专业版显得便宜）

**价值表达公式（销售必背）：**
```
"您现在请一个仓管 + 录入员，月人力成本约 ¥10,000-15,000，
还要管社保、培训、流失、出错、加班。

智能体一个月只要 ¥2,800，相当于人力成本的 1/5 - 1/10。
而且：
 ✓ 7×24 不下班
 ✓ 0 出错率
 ✓ 0 离职风险
 ✓ 数据全留痕
 ✓ 老板手机随时看
 
一年省 ¥10 万+，够您再开一个分公司。"
```

## 三、6 大预售机制

### 🥇 机制 1：限量"创始客户"特权

**规则：**
- 仅限**前 100 家**客户
- 享受**永久 7 折续费 + 价格锁定 + 创始人微信 + 行业曝光**

**适合：** S 层 / A 层  
**预期转化：** S 层 100% + A 层 30%

### 🥈 机制 2：阶梯定金锁单

| 方案 | 定金 | 抵扣 | 退款 | 适合 |
|------|------|------|------|------|
| 轻试用 | ¥1 | 0 | 30 天可退 | 全部 |
| 占席位 | ¥1,000 | 抵 ¥2,000 | 30 天可退 | A/B 层 |
| 创始锁定 | ¥6,000 | 抵 ¥12,000 | 14 天可退 | S/A 层 |

### 🥉 机制 3：限时早鸟阶梯

```
首批 30 家  → 5 折        最低 ¥800/月起
31-80 家    → 6 折        最低 ¥960/月起
81-150 家   → 7 折        最低 ¥1,120/月起
151-300 家  → 8 折        最低 ¥1,280/月起
正式上线后  → 原价
```

### 🎖️ 机制 4：14 天免费试用

- 不要钱，但要"承诺试用"
- 上传商家任意一个月的真实业务数据
- 第 1 周由智能体处理，老板和原员工对比
- 第 2 周给出 ROI 报告
- 试用结束当天，**销售上门拿合同**
- 试用期完成转化率：**60-70%**

## 四、双角色转介绍机制

### 4.1 现实洞察

> 老板做决策，但**管理人员是"实际推动者"**：
> - 仓库主管想用库存智能体（自己累）
> - 财务主管想用出纳智能体（对账太烦）
> - 业务经理想推荐给同行（多一个朋友）

### 4.2 双轨返佣分配

```
被介绍方：新客户 (老板 X)
   ↑
   │ 推荐
   │
转介绍方：可能是老板 也可能是管理人员
   │
   ├─ 如果是老板推荐 → 100% 返佣给老板（公司账户）
   │
   └─ 如果是管理人员推荐 → 老板 70% + 管理人员 30%
                          （或可选：老板 50% + 管理人员 50%）
```

### 4.3 老板转介绍激励包

> **老板要的是：面子 + 里子 + 关系**

| 激励 | 说明 |
|------|------|
| 现金返佣 | 每成功推荐 1 家：¥2,000-5,000（合同金额 10-15%） |
| 累进奖励 | 3 家：+¥3,000；5 家：+¥10,000；10 家：+¥30,000 |
| 自身续费 | 推荐 1 家 = 自己服务费续 1 个月 |
| 关系背书 | 平台年度峰会"金牌推荐人"奖牌 |
| 行业曝光 | 公众号/视频号案例传播 |
| 专属服务 | 老板专属客服 + 创始人微信 |
| 战略身份 | "推荐大使"身份证书 |

### 4.4 管理人员转介绍激励包

> **管理人员要的是：实利 + 成长 + 私利**

| 激励 | 说明 |
|------|------|
| 现金返佣 | 每成功推荐 1 家：¥600-1,500 现金（个人账户） |
| 替代选项 | 京东卡 / 加油卡 / 美团卡（避税方便） |
| 实物礼品 | 3 家：苹果手表；5 家：iPhone；10 家：¥5,000 购物卡 |
| 学习成长 | 行业培训免费名额（管理 / AI 应用） |
| 行业晋升 | "金牌业务员"认证证书 |
| 朋友圈晒单 | 个性化海报、易于分享的素材 |
| 个人荣誉 | 月度排行榜，奖金 + 截图 |

### 4.5 关键技术支撑

- **专属推荐码**：每个老客户（含老板和员工）都有
- **二维码 / 链接 / 海报**：一键生成
- **系统自动追踪**：谁推荐 → 谁注册 → 谁付费 → 自动结算
- **透明追踪面板**：实时查看进度 + 排行榜
- **返佣到账速度**：T+7（避免退款风险）

### 4.6 防作弊机制

| 风险 | 应对 |
|------|------|
| 老客户自己注册 | 推荐码与被推荐人主体不能关联 |
| 公司内部互推 | 法人 / 信用代码 / 税号查重 |
| 假合同套返佣 | 必须真实付款 + 7 天后结算 |
| 一单多推 | 系统按"首推"锁定推荐人 |
| 员工跳槽 | 离职 30 天内推荐仍归原公司 |

## 五、种子客户长期政策（预售只是起点）

### 5.1 3 大终身特权

#### 特权 1：价格永久锁定 + 7 折续费
- 即使官方涨价 50%，他永远享受 7 折
- 续费 3 年额外送 6 个月
- 每年涨价时给他发"您依然是最低价"通知

#### 特权 2：产品共建身份
- **PRD 评审权**：新功能上线前发给他征求意见
- **内测权**：所有新智能体最早体验
- **命名权**：每年 1 个新功能由种子客户命名
- **季度闭门会议**：直接和创始人对话

#### 特权 3：行业资源圈
- **种子客户专属群**（创始人/CTO 在内）
- **每年 2 次峰会**：全国种子客户聚会
- **行业资源对接**：上下游介绍、贷款、招聘
- **政策抢先获悉**：行业政策、税务变化第一时间通知

### 5.2 种子客户成长曲线

```
T+0      签约        【种子客户】身份开通
T+30     完成上线    专属"上线感谢礼"（行业书籍 + 老板雨伞）
T+90     首次评估    第一份"ROI 报告"（量化省了多少）
T+180    深度服务    创始人电话回访
T+365    周年纪念    "种子周年"礼盒 + 续费 8 折升级
T+365+   持续增值    新产品免费试用 + 推荐返佣
```

### 5.3 种子客户的 3 个使命

| 使命 | 平台收益 | 客户回报 |
|------|---------|---------|
| 1. 提供反馈 | 产品迭代依据 | 共建身份 + 个人荣誉 |
| 2. 介绍同行 | 病毒拉新 | 现金返佣 + 关系扩展 |
| 3. 案例代言 | 品牌背书 | 公司曝光 + 行业地位 |

### 5.4 退出成本设计（让他舍不得走）

```
持续锁定机制：
  • 第 1 年：享受 5 折特权
  • 第 2 年：续费免 1 个月（如不续，等于亏）
  • 第 3 年：终身 7 折升级到旗舰版
  • 累计 3 年：享受"白金种子"身份（永久免费 1 个智能体）

数据沉淀：
  • 历史业务数据全部沉淀在平台
  • 离开 = 数据迁移成本极高
  • 团队习惯 = 培训成本
  
人脉沉淀：
  • 创始人微信、行业群关系
  • 离开 = 关系断裂
```

## 七、必须避免的 5 个坑

### ❌ 坑 1：定价过低
预售价**绝对不能低于 7 折**，否则正式上线后客户觉得吃亏，会闹。

### ❌ 坑 2：免费试用太长
14 天足够，超过 1 个月客户拖延决策。

### ❌ 坑 3：返佣模糊
必须**透明、即时、可查**，否则推荐人不会卖力。

### ❌ 坑 4：服务跟不上
预售签约越多，服务压力越大。**预售前必须备好 3 倍服务团队**。

### ❌ 坑 5：忽视员工
只激励老板，员工不动。**双角色返佣是关键**。

## 九、关键风险与应对

### 9.1 业务风险

| 风险 | 概率 | 应对 |
|------|------|------|
| 客户对 AI 接受度低 | 中 | 14 天试用 + ROI 报告 + 案例传播 |
| 转化率不达标 | 低 | 周度复盘 + 动态调整机制 |
| 老客户流失 | 低 | 创始人客户的特殊维护 |
| 竞品打价格战 | 中 | 创始客户价格永久锁定承诺 |
| 服务跟不上 | 高 | 预售前备好 3 倍客户成功团队 |

### 9.2 财务风险

| 风险 | 应对 |
|------|------|
| 大量退款 | 服务质量监控 + 预留 20% 退款准备金 |
| 返佣成本失控 | 设置返佣总预算上限（¥100 万） |
| 客单价过低 | 销售考核加 ACV 权重，鼓励卖高套餐 |

### 9.3 合规风险

| 风险 | 应对 |
|------|------|
| 推广话术违规 | 法务审核所有营销物料 |
| 个人信息收集 | 隐私政策明确告知 |
| 个人返佣涉税 | 总额 ≥ ¥800/年由公司代扣个人所得税 |
