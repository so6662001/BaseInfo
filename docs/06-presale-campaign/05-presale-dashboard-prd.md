> 版本：v1.0  
> 适用对象：产品经理、研发工程师、数据分析师、运营总监  
> 输出物：完整大屏需求文档 + 数据指标体系 + 接口设计

---

## 一、产品定位

### 1.1 业务目标

为预售作战提供**实时、全方位、多角色**的数据可视化监控，让团队：

- **老板**：30 秒内掌握整体战况
- **运营总监**：实时识别问题、调整策略
- **销售总监**：识别销售排名 + 发现 Top 销售
- **客户经理**：实时跟踪自己的客户进度
- **数据团队**：复盘 + 优化 + 预测

### 1.2 设计原则

1. **3 秒理解** - 关键指标巨大字号，一眼看到
2. **5 层钻取** - 从总览到明细，5 次点击触达
3. **5 分钟刷新** - 实时性平衡（避免压垮系统）
4. **多端适配** - 大屏 + PC + 手机
5. **角色化视图** - 不同角色看不同信息

## 七、数据指标体系

### 7.1 核心指标

| 指标 | 定义 | 计算公式 | 刷新频次 |
|------|------|---------|---------|
| **签约数** | 已完成正式签约的客户数 | COUNT(签约状态) | 实时 |
| **目标完成率** | 当前 / 目标 | 签约数 / 200 | 实时 |
| **预测达标** | 预计最终达成数 | 当前 + 在途漏斗 × 历史转化率 | 每小时 |
| **GMV** | 总合同金额 | SUM(合同金额) | 实时 |
| **ARPU** | 平均合同价值 | GMV / 签约数 | 实时 |
| **转化率（试用→签约）** | 试用客户中签约比例 | 签约数 / 试用数 | 每小时 |
| **平均决策时长** | 注册到签约平均天数 | AVG(签约时间 - 注册时间) | 每天 |

### 7.2 漏斗指标

| 阶段 | 名称 | 上一级转化率 |
|------|------|------------|
| 1 | 触达 | - |
| 2 | 注册 | 注册数 / 触达数 |
| 3 | 试用申请 | 试用 / 注册 |
| 4 | 定金支付 | 定金 / 试用 |
| 5 | 合同签约 | 签约 / 定金 |
| 6 | 首次付款 | 付款 / 签约 |

### 7.3 销售指标

| 指标 | 定义 |
|------|------|
| 销售签约数 | 个人签约数 |
| 销售 GMV | 个人 GMV |
| 销售提成 | 个人本月提成 |
| 销售客户数 | 在跟客户数 |
| 销售响应速度 | 平均响应时长 |
| 销售拜访数 | 月度拜访 |
| 销售通话数 | 月度通话 |

### 7.4 客户指标

| 指标 | 定义 |
|------|------|
| 客户分层 | S/A/B/C |
| 客户来源 | 邀请/推广/转介绍/广告 |
| 客户决策周期 | 注册-签约天数 |
| 客户套餐 | 入门/标准/专业/旗舰 |
| 客户 LTV | 预期 3 年价值 |
| 客户留存率 | 月度留存 |

### 7.5 推荐人指标

| 指标 | 定义 |
|------|------|
| 推荐人数 | 推荐过 ≥ 1 家的人数 |
| 平均推荐数 | 总推荐数 / 推荐人数 |
| 推荐转化率 | 推荐转签约 % |
| 返佣总额 | 已发放 |
| 待结算返佣 | 未到 T+7 |
| 顶级推荐人 | Top 10 |

## 八、技术实现

### 8.1 数据采集

```
业务数据层（MySQL）
  ↓ Binlog
数据集成（Canal / Debezium）
  ↓
消息队列（Kafka）
  ↓
实时计算（Flink）
  ↓
OLAP 存储（Doris / ClickHouse）
  ↓
大屏服务（Spring Boot + WebSocket）
  ↓
前端展示（ECharts / DataV）
```

### 8.2 关键技术栈

| 层 | 技术 |
|----|------|
| 数据存储 | MySQL（业务）+ Doris（OLAP） |
| 实时计算 | Apache Flink |
| 消息队列 | Apache Kafka / RocketMQ |
| 缓存 | Redis |
| 后端 | Spring Boot + WebSocket |
| 前端 | Vue 3 + ECharts / DataV |
| 大屏 | DataV / 自研 |

### 8.3 数据更新频率

| 数据类型 | 更新方式 | 频率 |
|---------|---------|------|
| 关键指标（签约、漏斗）| WebSocket 推送 | 实时 |
| 中等优先级（排名）| 轮询 | 5 分钟 |
| 趋势数据 | 定时计算 | 1 小时 |
| 报表数据 | 离线计算 | T+1 |

### 8.4 性能要求

- 大屏首屏加载 ≤ 3 秒
- 数据刷新延迟 ≤ 5 秒
- 同时在线 100 人无压力
- 高峰 QPS ≥ 1000
