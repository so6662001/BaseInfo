# 方案三：应收账款保理 - PRD

> 版本：v1.0  
> 产品定位：钢贸行业供应链金融服务平台

---

## 1. 业务概述

### 1.1 业务背景

- 钢贸 70%+ 是赊销，平均账期 30-90 天
- 商家普遍资金紧张，依赖银行流贷或民间借贷
- 银行授信难、额度小、流程慢，民间利率年化 18-36%
- 商家手里大量优质应收账款（应收方为大型央企、上市公司）但无法变现

### 1.2 产品定位

**货袋子供应链金融平台**：基于平台 ERP 真实数据 + 信用查询数据 + 交易数据，为钢贸商家提供：
- 应收账款保理（核心）
- 信用贷
- 订单融资
- 仓单质押

### 1.3 核心用户

| 角色 | 说明 |
|------|------|
| 融资方（商家） | 平台认证商家，需要资金周转 |
| 资金方 | 合作银行 / 商业保理 / 平台自营保理 |
| 应收方（核心企业） | 应收账款债务人 |
| 平台 | 数据风控 + 资金通道 + 监管账户 |

### 1.4 业务边界

| 范围内 | 范围外 |
|--------|--------|
| 平台认证商家融资 | 非平台用户（暂不） |
| 应收账款 / 仓单 / 订单 / 信用贷 | 个人消费贷（不做） |
| 钢贸行业及上下游 | 其他行业 |
| 与持牌机构合作 | 自营无证放贷（不做） |

## 3. 核心金融产品矩阵

### 3.1 货袋子贷（信用贷）- 入门款

| 要素 | 规则 |
|------|------|
| 适用对象 | 平台 ERP 使用 ≥ 6 个月 + 经营 ≥ 1 年 + 信用 ≥ A |
| 授信额度 | ¥30 万 - ¥500 万 |
| 期限 | 1-12 个月，循环授信 |
| 利率 | 月费率 0.6%-0.85%（年化 7.2%-10.2%） |
| 还款方式 | 先息后本 / 等额本息 |
| 增信措施 | 法人个人连带责任 |
| 放款时效 | T+1 |
| 资金方 | 合作银行（网商/新网/众邦等） |

### 3.2 应收账款保理（核心产品）

| 要素 | 规则 |
|------|------|
| 适用对象 | 应收账款方为 A 级以上企业 |
| 融资比例 | 应收金额的 70%-90% |
| 期限 | 与应收账期一致（30-180 天） |
| 利率 | 月费率 0.5%-0.7%（年化 6%-8.4%） |
| 追索权 | 无追索权（标准）/ 有追索权（折扣低） |
| 必备凭证 | 合同 + 发货单 + 签收单 + 发票 + 银行流水 |
| 确权方式 | 应收方电子确权（或线下确权） |
| 放款时效 | T+1（已确权）/ T+3（未确权） |
| 资金方 | 合作保理 / 银行 / 平台自营保理 |

### 3.3 订单融资（上游用）

| 要素 | 规则 |
|------|------|
| 适用对象 | 已签订销售合同，需要采购原料的商家 |
| 融资比例 | 订单金额的 60-80% |
| 期限 | 不超过订单履约周期 |
| 利率 | 月费率 0.7%-0.9% |
| 资金用途 | 定向支付给上游钢厂（封闭运行） |
| 还款 | 销售款回款后归还 |
| 风控 | 订单合同 + 上游开票 + 物流监督 |

### 3.4 仓单质押（抵押贷）

| 要素 | 规则 |
|------|------|
| 适用对象 | 货物在平台合作仓库（云仓） |
| 融资比例 | 货值的 60-70% |
| 期限 | 1-6 个月 |
| 利率 | 月费率 0.5%-0.7% |
| 增信 | 仓单质押 + 价格波动追保 |
| 风控 | 价格 > 10% 跌幅 → 触发追保或处置 |

### M1 - 授信申请

#### M1.1 预授信展示

商家登录后，工作台首页展示：

```
┌─────────────────────────────────┐
│  💰 您的预授信额度              │
│                                 │
│  ¥1,200,000                    │
│  基于您的 ERP 数据自动评估      │
│                                 │
│  • 信用贷可用：¥800,000        │
│  • 应收保理可用：¥1,200,000    │
│  • 仓单质押可用：¥600,000      │
│                                 │
│  [立即申请] [了解详情]           │
└─────────────────────────────────┘
```

#### M1.2 授信申请流程

```
Step 1：选择产品（货袋子贷/保理/订单融资/仓单质押）
        ↓
Step 2：基本信息（系统已预填）
        - 营业执照
        - 法人身份证
        - 财务报表（近 2 年）
        - 银行流水（近 12 月）
        ↓
Step 3：补充材料（按产品要求）
        - 货袋子贷：法人征信授权
        - 保理：应收账款明细 + 凭证
        - 订单融资：销售合同
        - 仓单质押：仓单 + 货物清单
        ↓
Step 4：电子签合同
        - 借款合同
        - 担保合同（如有）
        - 数据授权书
        ↓
Step 5：风控审批
        - 系统自动初审（30 秒）
        - 资金方复审（≤ 30 分钟）
        ↓
Step 6：放款
        - 资金到达指定账户
        - APP 通知 + 短信
```

#### M1.3 授信额度计算

```
综合授信额度 = MIN(
    ERP 月均流水 × 3,
    资产净值 × 50%,
    应收账款 × 80%,
    历史最大借贷 × 1.5,
    资金方上限
)

定价利率 = 基础利率 + 风险溢价
  基础利率 = 4.5%（资金方成本）
  风险溢价 = 信用等级风险 + 行业风险 + 地区风险
    AAA：+0.5%-1%
    AA：+1%-2%
    A：+2%-3%
    B：+3%-5%
```

### M3 - 应收账款保理

#### M3.1 应收账款上传

商家可通过两种方式上传应收：

**方式一：从 ERP 自动同步**
- 平台读取商家 ERP 应收账款表
- 自动识别 A 级以上应收方
- 商家勾选要融资的应收

**方式二：手动上传**
- 上传应收账款明细（Excel）
- 上传相关凭证（合同/发货单/签收单/发票）

#### M3.2 应收方信用评估

平台调用方案一【信用查询】对应收方做评估：

```
应收方信用评级：
  AAA - 融资比例 90% / 利率 0.5%
  AA  - 融资比例 85% / 利率 0.55%
  A   - 融资比例 80% / 利率 0.6%
  B   - 融资比例 70% / 利率 0.7%
  C/D - 不接受
```

#### M3.3 确权流程

```
平台向应收方发起电子确权：

【应收账款确权通知】
亲爱的【上海XX建材有限公司】：

您与【商家A】于 2025-09-15 签订的合同
（合同号：HT2025091500X，金额：¥850,000）
对应的应收账款，商家A 拟将该应收账款转让
给【XX商业保理公司】用于融资。

请您在 7 个工作日内确认：
1. 该笔应收账款真实存在
2. 应付款日期：2025-12-15
3. 同意将应付款项支付至以下指定账户：
   开户行：XX银行
   账号：XXX XXX XXX
   户名：XX商业保理公司

[同意] [拒绝] [咨询]
```

确权方式：
- 电子确权（推荐）：应收方在线确认
- 邮寄确权：寄送纸质确认书
- 双录确权：电话录音 + 视频
- 线下确权：业务员上门确认

#### M3.4 保理融资流程

```
应收上传 → 平台自动校验真实性
      • 合同电子签真实性 ✓
      • 物流签收回单 ✓
      • 发票真实性（税务系统校验）✓
      • 应收方信用 ≥ A
      ↓
确权（应收方确认）
      ↓
资金方审批（< 1 工作日）
      ↓
保理放款（应收 70-90% × 期限利率）
      ↓
资金进入商家专属监管账户
      ↓
账期到期 → 应收方付款给【保理监管账户】
      ↓
扣除融资款本金 + 利息
      ↓
余额返还商家
```

#### M3.5 池保理（增值产品）

- 商家可将多笔小额应收"打包"成保理资产池
- 减少单笔申请频次，降低操作成本
- 资金方按池整体评估，利率更优惠

### M4 - 订单融资

#### M4.1 适用场景

```
场景：商家接到一笔大订单，但缺采购原料的资金
   ↓
商家：上传销售合同 + 上游采购合同
   ↓
平台：评估订单真实性 + 上下游信用
   ↓
放款：资金定向支付给上游钢厂
   ↓
商家收到货 → 加工/转售 → 客户付款
   ↓
还款：销售回款进入监管账户，自动归还融资
```

#### M4.2 风控要点

- 销售合同真实性（电子签 + 客户确权）
- 客户信用等级 ≥ A
- 上游钢厂为合作钢厂（白名单）
- 订单履约时间合理
- 资金封闭运行

### M5 - 仓单质押

#### M5.1 适用场景

商家货物存放于平台合作云仓，可申请仓单质押融资。

#### M5.2 流程

```
货物入库 → 平台仓库出具电子仓单
   ↓
商家申请仓单质押 → 选择质押货物
   ↓
平台估值（按当日市场价 × 折扣率 70%）
   ↓
质押锁定（仓库不允许出库）
   ↓
放款（货值 60-70%）
   ↓
还款 → 解除质押 → 货物可正常出库
```

#### M5.3 价格预警机制

- 实时监控质押货物市场价
- 跌幅 ≥ 5% → 黄色预警，建议补保证金
- 跌幅 ≥ 10% → 红色预警，强制追保 24h 内
- 跌幅 ≥ 15% → 平台启动处置（出售）

### M8 - 风控引擎

#### M8.1 三道防线

```
【第一道：事前风控】
  • 准入校验：经营 ≥ 1 年 + ERP 数据 ≥ 6 个月 + 信用 ≥ A
  • 额度模型：5 维度评估
  • 反欺诈：黑产识别、关联账号、身份核验

【第二道：事中监控】
  • 经营异常监控（流水突降 30%+）
  • 价格异常监控
  • 应收变化监控
  • 关联企业风险监控
  • 行业系统性风险

【第三道：事后处置】
  • 早期催收（逾期 7 天内电话）
  • 法务催收（30 天）
  • 资产保全（60 天）
  • 转让坏账资产包（90 天）
```

#### M8.2 风控模型

```python
# 综合授信评分

授信分 = 经营稳定 × 0.25 + 财务健康 × 0.30 + 交易真实 × 0.25 + 行业风险 × 0.20

【经营稳定 (25%)】
  • ERP 数据连续性
  • 工商注册年限
  • 经营场所稳定性
  • 员工人数稳定性

【财务健康 (30%)】
  • 资产负债率
  • 流动比率
  • 销售增长率
  • 银行流水稳定性

【交易真实 (25%)】
  • 物流凭证完整度
  • 电子签收率
  • 合同签章
  • 上下游分散度

【行业风险 (20%)】
  • 行业景气指数
  • 区域风险
  • 价格波动
  • 政策风险
```

#### M8.3 关键风控指标

| 指标 | 数据源 | 风险信号 |
|------|--------|---------|
| 月营业额波动 | ERP 销售 | 突然下滑 30% |
| 客户集中度 | ERP 客户 | 单一客户 > 50% |
| 应收账款周转 | ERP 应收 | 突然延长 50% |
| 库存周转 | ERP 库存 | 突然减半 |
| 上下游分散度 | ERP 采购+销售 | 过度集中 |
| 价格异常 | 平台行情 | 高/低于市场 ±20% |
| 经营行为 | 平台行为 | 突然减少登录 |
| 关联企业 | 工商图谱 | 关联出问题 |

## 6. 非功能需求

### 6.1 性能

- 授信预评估响应 ≤ 3 秒
- 借款申请提交 ≤ 1 秒
- 审批结果返回 ≤ 30 分钟（信用贷）/ 1 工作日（保理）
- 放款时效 ≤ T+1

### 6.2 安全合规

- 持牌机构资金方（不自营无证放贷）
- 银行存管资金（资金不入平台账户）
- 客户数据加密存储 + 传输
- 等保三级认证
- 符合《商业银行互联网贷款管理暂行办法》《保理业务管理办法》

### 6.3 可靠性

- 系统可用性 99.95%
- 资金交易零差错
- 灾备：异地双活
