## 9. 交互说明

### 9.1 关键原则

1. **流程极简**：5 步内完成保理申请
2. **数据预填**：基于 ERP 数据自动带入，减少手动录入
3. **进度透明**：每个状态节点清晰可见
4. **资金安全感**：强调"银行存管""持牌机构"
5. **应收方友好**：确权流程不能太复杂，否则确权率低

### 9.2 风控强提示

每个借款页面必须显示：
- 当前利率（年化标识）
- 还款总额
- 法律提示（《借款合同》风险提示）
- 征信查询授权
- 不得用于违法用途
