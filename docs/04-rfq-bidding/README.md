# 方案四：安全版询价竞价

> **战略定位：服务大客户、引入大订单，但必须保护商家**

## 一、为什么是"安全版"

行业里"询价竞价"长期被视为**伤害商家的工具**：买家发询价，商家互相压价，价格透明、利润归零、客户被撬。找钢网早期吃过这个大亏。

货袋子的"安全版"竞价，不是再造一个找钢网，而是用 **4 大保护机制** 让竞价服务于双方：
1. 只对**大客户**开放
2. 报价**单向透明**（买家看得到，商家互盲）
3. **多维评分**（不只是价格）
4. **老客户保护**（防撬单）

## 二、核心价值主张

| 视角 | 价值 |
|------|------|
| 大客户买家 | 一次询价多家响应、价格透明、节省时间 |
| 商家卖家 | 可控的招标场景，不被同行恶意压价，可保护老客户 |
| 平台 | 引入大额订单 GMV，激活商家供给侧 |
