## 10. 交互说明

### 10.1 关键交互原则

1. **结构化优先**：所有商品必须按标准 SKU 结构化，禁止自由输入
2. **价格透明**：每条库存都对比平台市场价，让买家算账方便
3. **撮合主动**：系统主动 push 匹配的库存给买家，不被动等浏览
4. **担保强化**：每个交易步骤强调"平台担保""资金安全"
5. **物流可视**：物流跟踪 = 用户最敏感的体验，必须做到极致

### 10.2 移动优先

- APP 端做主操作（钢贸老板/销售员主要在外面跑）
- PC 端做管理（财务对账、库存批量管理）

### 10.3 数据可信度提示

- 所有 SKU 标准化标识（绿色对勾）
- 卖家信用等级（AAA-D 颜色标识）
- 平台担保标识（盾牌 icon）
- 历史成交数据（数字越大越可信）
