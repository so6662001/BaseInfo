## 9. 交互说明

### 9.1 关键原则

1. **保护商家**：所有报价信息单向透明，商家间互盲
2. **大客户友好**：流程简洁，结构化录入，一次询价多家响应
3. **公平竞标**：评分算法公开透明，可解释、可申诉
4. **老供应商优先**：通过加分机制保护现有供应关系
5. **价格底线**：禁止恶性低价（系统拦截）

### 9.2 移动 vs PC

- **PC 端为主**：买家招标管理、商家报价（功能复杂）
- **APP 端补充**：消息通知、简单查询、移动报价

### 9.3 反作弊提示

每个报价页面强调：
- 价格底线提示（禁止低于成本）
- 围标识别提示（系统监控）
- 履约保证金（违约扣除）
