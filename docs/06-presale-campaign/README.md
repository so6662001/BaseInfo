## 四、预售 6 大机制速览

1. **创始客户特权**（仅 100 家，永久 7 折）
2. **阶梯定金锁单**（¥1 / ¥1000 / ¥6000 三档）
3. **限时早鸟阶梯**（首批 5 折，按批次涨价）
4. **14 天免费试用**（真实数据 + ROI 报告）
5. **3 人成团购买**（团长享免费月）
6. **双轨现金返佣**（老板 + 管理人员）

## 九、关于 5 大方案的协同

本预售方案不是孤立的。AI 智能体作为新产品线，与之前的 5 大方案形成完整生态：

```
方案五（商家分层）→ 提供精准客户分层标签
   ↓
方案一（信用查询）→ 推介时降低决策风险
   ↓
方案三（保理金融）→ 客户用智能体省钱后→反过来用金融服务
   ↓
方案二/四（库存/竞价）→ 智能体使用频次提升后→平台 GMV 提升
   ↓
预售种子客户 → 反哺各方案的 NPS / 案例 / 转介绍
```

预售种子客户 = 货袋子整个生态的"超级用户"。
