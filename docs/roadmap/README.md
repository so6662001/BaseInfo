# 货袋子平台 - 90 天 MVP 项目作战地图

> 适用阶段：从现状到第一波杀手级功能上线  
> 核心目标：90 天内，完成方案一（信用查询黑名单）MVP + 启动方案五（商家分层激活）+ 准备方案二（库存共享池）

---

## 一、90 天战略目标

### 1.1 总目标

> 把 **2000 家 ERP 商家** 中的 **300 家** 激活为信用查询的活跃用户，启动平台数据飞轮和病毒传播。

### 1.2 量化目标

| 指标 | 90 天目标 |
|------|---------|
| 注册激活商家 | 800（占 ERP 用户 40%）|
| 月活查询商家 | 300 |
| 累计客户档案 | 5 万 |
| 月查询次数 | 3 万 |
| 商家上报欠款 | 500 |
| 商家分层完成 | 100% （2000 家全部分层）|
| 客户经理团队 | 招聘到位（KAM 5 人 + 运营 3 人）|

---

## 二、90 天阶段拆解

### 阶段一：奠基（Day 1-30）

#### Week 1-2：项目启动 + 数据基础

- 项目章程、KPI 体系、组织架构落定
- 启动 ERP 数据治理（清洗、统一 SKU、统一客户库）
- 接入企查查 / 天眼查 API
- 商家分层模型 V0（基于现有数据）

#### Week 3-4：信用查询 MVP 后端

- 客户档案基础表 + 数据导入
- 信用查询 API 开发
- 简单评分模型（V0）
- 后台数据治理工具

### 阶段二：发布（Day 31-60）

#### Week 5-6：信用查询 MVP 前端 + 测试

- APP 端信用查询页面
- PC 端信用查询主页
- 简单上报功能
- 内部测试

#### Week 7-8：种子用户灰度

- 邀请 50 家种子商家试用
- 收集反馈、迭代 2 个版本
- 客户经理一对一陪跑
- 商家分层 V1（自动）

### 阶段三：放量（Day 61-90）

#### Week 9-10：全量推广

- 全量 2000 家 ERP 商家邀请
- 营销自动化触达上线
- 邀请裂变机制启动
- 黑名单广场上线

#### Week 11-12：迭代优化 + 数据复盘

- 信用查询 V1.0 上线（评分模型 + 共建积分）
- 库存共享池技术预研开始
- 90 天数据复盘

## 六、风险与应对

| 风险 | 应对 |
|------|------|
| ERP 数据治理超期 | 优先治理头部商家数据，长尾分批 |
| 第三方 API 不稳 | 多源备份（企查查 + 天眼查）|
| 种子用户反馈差 | 调整产品策略，必要时延期 |
| 客户经理招聘难 | 内部培养 + 外包合作 |
| 产品 Bug 影响推广 | 灰度发布 + 快速回滚 |

## 七、成功标志

完成以下任意 3 项即认为 90 天成功：

- ✅ 月活查询商家 ≥ 300 家
- ✅ 单个商家平均月查询 ≥ 10 次
- ✅ 商家共建上报数 ≥ 500 条
- ✅ 邀请裂变拉新 ≥ 100 家
- ✅ NPS 评分 ≥ 50
- ✅ 至少 1 家商家公开案例传播
