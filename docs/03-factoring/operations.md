# 方案三：应收账款保理 - 运营策略

---

## 1. 推广策略

### 1.1 冷启动（前 6 个月）

#### 第一波：种子商家（30 家）
- 从 2000 家 ERP 商家中筛选 **资质好、规模适中**的商家
- 标准：经营 ≥ 2 年 + ERP 数据 ≥ 12 月 + 信用 ≥ AA
- 一对一上门服务，**首笔保理利率减半**
- 目标：3 个月内，30 家累计放款 ¥3000 万

#### 第二波：标杆案例（50 家）
- 邀请第一波种子商家做案例
- 制作"商家成功故事"视频："商家A 通过货袋子保理，30 天到账 ¥720 万，省了去银行排队的 20 天"
- 目标：6 个月内 50 家累计放款 ¥1 亿

#### 第三波：行业事件
- 联合钢厂/银行举办"钢贸金融服务峰会"
- 行业 KOL 直播解读
- 目标：触达 5000+ 钢贸老板

### 1.2 增长期（6-18 个月）

#### 资金方扩张

| 优先级 | 资金方类型 | 目标家数 | 目标合作额度 |
|-------|----------|---------|------------|
| P0 | 互联网银行（网商/新网/众邦）| 3 家 | ¥10 亿 |
| P1 | 国有大行供应链金融部 | 2 家 | ¥20 亿 |
| P2 | 股份制银行 | 3 家 | ¥10 亿 |
| P3 | 头部商业保理 | 5 家 | ¥10 亿 |

#### 产品矩阵推进
- M+1：货袋子贷上线（信用贷）
- M+3：应收保理上线（核心）
- M+6：订单融资上线
- M+9：仓单质押上线
- M+12：池保理 + ABS

### 1.3 成熟期（18 个月+）

- 自建商业保理公司（控股 / 独资）
- 资产证券化（ABS）：将应收资产打包发行
- 跨行业拓展：上下游加工厂、钢厂金融服务
- 数据 API 服务：开放给银行做外部风控

## 3. 风控管理

### 3.1 三道防线

```
【第一道：事前】
  ├─ 准入门槛
  │  • 营业 ≥ 1 年
  │  • ERP ≥ 6 月
  │  • 信用 ≥ A
  │  • 法人无重大不良
  ├─ 额度模型
  └─ 反欺诈
     • 黑产识别
     • 关联账户
     • 身份核验
     • 设备指纹

【第二道：事中】
  ├─ 经营异常监控（每日）
  ├─ 价格异常监控
  ├─ 应收变化监控
  ├─ 关联企业风险
  └─ 行业系统性风险

【第三道：事后】
  ├─ 早期催收（< 7 天）
  │  • 自动短信 + APP Push
  │  • 客户经理电话
  ├─ 中期催收（7-30 天）
  │  • 上门拜访
  │  • 法务函
  ├─ 法律催收（30-90 天）
  │  • 律师函
  │  • 起诉
  ├─ 资产保全（60 天+）
  │  • 财产查封
  │  • 银行冻结
  └─ 不良处置（90 天+）
     • 转让坏账资产包
     • 计提坏账
     • 行业警示
```

### 3.2 关键风控指标监控

| 指标 | 阈值 | 处置 |
|------|------|------|
| 单户授信 | < 单户上限 5% | 自动 |
| 单行业集中度 | < 30% | 控制 |
| 单地区集中度 | < 25% | 控制 |
| 90 天逾期率 | < 1.5% | 警戒 |
| 30 天首逾率 | < 3% | 监控 |
| 不良率 | < 2% | 容忍上限 |
| 资金方风险敞口 | < 资金方授信 95% | 限额 |

### 3.3 反欺诈

| 欺诈类型 | 识别方法 |
|---------|---------|
| 套现欺诈 | 资金流向分析 + 关联企业 |
| 虚假应收 | 物流凭证 + 税务系统验票 |
| 借新还旧 | 资金用途监控 |
| 关联交易 | 工商图谱 + 资金流匹配 |
| 资料造假 | OCR + 多源交叉验证 |
| 团伙欺诈 | 设备指纹 + 行为聚类 |

## 4. 合规管理

### 4.1 监管合规

| 合规要求 | 应对 |
|---------|------|
| 商业银行互联网贷款管理办法 | 与持牌银行合作，不自营无证放贷 |
| 商业保理企业管理办法 | 自建保理需取得商业保理资质 |
| 个人信息保护法 | 数据授权 + 加密存储 + 最小化原则 |
| 数据安全法 | 等保三级 + 数据出境合规 |
| 反洗钱法 | 大额交易报告 + 可疑交易报告 |
| 征信业管理条例 | 获取个人征信需明确授权 |

### 4.2 必备资质

| 资质 | 主体 | 优先级 |
|------|------|-------|
| ICP 经营许可 | 平台 | P0 |
| 等保三级认证 | 平台 | P0 |
| 资金方合作协议 | 平台 + 资金方 | P0 |
| 商业保理牌照（如自营） | 子公司 | P2 |
| 小贷牌照（如自营贷款） | 子公司 | P2 |
| 网络小贷牌照 | 子公司 | P3 |

### 4.3 合规底线

- ❌ 严禁自营无证放贷
- ❌ 严禁砍头息
- ❌ 严禁年化超过 24% 的利率
- ❌ 严禁暴力催收
- ❌ 严禁资金挪用
- ✅ 全部资金银行存管
- ✅ 全部合同电子签 + 法律审核
- ✅ 全部业务接受监管检查

## 6. 商业化模式

### 6.1 收费结构

| 模式 | 收益来源 | 适用阶段 |
|------|---------|---------|
| 导流模式 | 一次性导流费 1-2% | 起步阶段 |
| 助贷模式 | 利差分成 10-30% | 成长阶段 |
| 联合贷款 | 利差分成 30-50% | 成长阶段 |
| 自营保理 | 全部利差 | 成熟阶段 |

### 6.2 收入测算

#### 助贷模式（成长期）

```
假设年放款 ¥10 亿，平均期限 4 个月，年化 9%
资金方成本：4.5%

利差 = 10亿 × (9% - 4.5%) × (4/12) = ¥1500 万
平台分成 30% = ¥450 万
+ 服务费 0.3% = ¥300 万
+ 数据/咨询 = ¥100 万
─────────────────────
合计：¥850 万/年
```

#### 自营保理（成熟期）

```
假设年放款 ¥30 亿，平均期限 4 个月，年化 9%
资金成本：5%（自筹/ABS）

利差 = 30亿 × (9% - 5%) × (4/12) = ¥4000 万
平台保留 80%（扣除运营成本）= ¥3200 万
+ 服务费 = ¥1000 万
+ 数据 API = ¥500 万
─────────────────────
合计：¥4700 万/年
```

## 7. 风险预案

### 7.1 单笔大额逾期

**场景**：单笔 ¥500 万+ 借款逾期

**预案**：
- 24h 内启动早期催收
- 7 天内法务介入
- 同步通知资金方
- 启动应急资金（如平台兜底）
- 评估处置方案

### 7.2 行业系统性风险

**场景**：钢贸行业整体下行（如 2015 年）

**预案**：
- 提前收紧授信（暂停高风险客户）
- 增加保证金要求
- 缩短期限
- 增强催收力度
- 启动行业风险白皮书提醒

### 7.3 资金方撤资

**场景**：合作银行 / 保理公司撤回额度

**预案**：
- 多资金方分散合作（不依赖单一）
- 动态调度其他资金方
- 应急资金池准备
- 借助 ABS 等资本市场工具

### 7.4 监管政策变化

**场景**：互联网金融监管政策收紧

**预案**：
- 法务团队实时跟踪
- 业务模式动态调整
- 主动与监管沟通
- 保持合规底线
