# 方案一：客户信用查询 + 黑名单系统 - PRD

> 版本：v1.0  
> 产品定位：钢贸行业 B 端客户信用征信平台

---

## 1. 业务概述

### 1.1 业务背景

- 钢贸行业 70%+ 是赊销，平均账期 30-90 天
- 行业坏账率 2-5%，单笔损失从几万到几百万不等
- 商家普遍依赖"销售员的客户嗅觉"做风控，缺乏数据支撑
- 失信客户在一家被骗后，往往换一家继续骗，行业内信息严重不对称

### 1.2 产品定位

**货袋子信用云**：基于平台 2000+ 家钢贸商 ERP 真实交易数据，结合工商、司法等外部数据，形成的钢贸行业 B 端客户征信平台。

### 1.3 核心用户

- **主要用户**：钢贸商家的财务、销售总监、老板
- **次要用户**：风控公司、保理机构、银行（API 调用）

### 1.4 业务边界

| 范围内 | 范围外 |
|--------|--------|
| B 端企业信用 | 个人征信（不做） |
| 钢贸行业及上下游 | 其他行业（暂不） |
| 商家共建数据 | 强制公开任何信息（不做） |
| 数据查询服务 | 任何形式的"信用评级"对外公开（不做） |

## 3. 详细功能需求

### M1 - 客户档案中心

#### M1.1 客户档案搜索

- **入口**：平台首页搜索框、APP 首屏、ERP 内嵌
- **搜索方式**：
  - 企业全称（模糊匹配）
  - 统一社会信用代码（精确匹配）
  - 法人姓名 + 注册地（组合匹配）
  - 历史交易客户（一键带入）
- **搜索结果**：
  - 同名匹配 → 按信用代码区分，显示 Top 5
  - 无匹配 → 实时调用工商 API 创建新档案
- **响应时间要求**：≤ 1.5 秒

#### M1.2 客户档案展示

档案分 6 大版块：

##### ① 基础信息
- 企业名称、统一社会信用代码、法人、注册资本、成立日期
- 经营状态（存续/吊销/注销/异常）
- 注册地址、经营地址、联系电话
- 行业分类、经营范围

##### ② 信用画像
- 综合信用分（0-1000）+ 信用等级（AAA/AA/A/B/C/D）
- 近 30/90/180 天信用分变化趋势
- 信用分各维度雷达图（5 维度）

##### ③ 平台交易记录
- 累计在 N 家商家有交易
- 累计交易额、平均订单额
- 平均账期、最长账期、最长逾期天数
- 当前未结欠款总额（脱敏：仅显示数额，不显示具体商家）
- 历史付款及时率

##### ④ 同行评价
- 星级评价（5 星制）+ 评价数量
- 文字评价列表（脱敏：商家名以 "商家A、商家B" 显示）
- 标签云：付款及时、要求严格、量大、信用好、有过逾期、跑路风险等

##### ⑤ 风险提示
- 工商风险：股权变更频繁、注册资本变更、经营异常
- 司法风险：被执行人、失信被执行人、诉讼记录
- 平台风险：被举报欠款、近期询价异常、关联企业风险
- 各风险项**红/黄/绿**三色标识

##### ⑥ 关联企业图谱
- 法人关联的其他企业
- 股东关联的其他企业
- 关联企业的风险传导

#### M1.3 信用报告下载

- 支持下载 PDF 版完整报告
- 报告包含：基础信息 + 信用画像 + 风险提示 + 平台交易摘要
- 报告 24 小时有效，超时自动失效（防止外传）
- 报告水印：商家名称 + 下载时间

### M4 - 商家上报中心

#### M4.1 欠款上报

**表单字段**：
- 客户名称（必填，自动联想）
- 客户信用代码（必填）
- 欠款金额（必填，¥）
- 欠款形成时间（必填）
- 应付款日期（必填）
- 当前状态（单选）：
  - 协商中
  - 拒付
  - 失联跑路
  - 已部分还款
  - 已全部追回（撤销上报）
- 关联订单号（选填）
- 备注说明（选填，500 字内）

**证据上传（必传至少 2 项）**：
- 销售合同 / 框架协议
- 发货单 / 签收单
- 银行流水（对账单）
- 沟通记录截图（微信、短信、邮件）
- 法律文书（律师函、判决书等）

**提交校验**：
- 系统提示《信用上报承诺书》
- 商家电子签名确认
- 警示：**恶意虚假上报将扣除 500 信用积分 + 封号**

#### M4.2 客户评价

**入口**：完成交易后自动邀请评价 / 客户档案页主动评价

**评价维度**：
- 综合星级（1-5 星）
- 付款及时性（1-5 星）
- 沟通配合度（1-5 星）
- 是否再合作（是/否）
- 文字评价（200 字内）
- 标签选择（多选）：
  - 付款及时、量大稳定、要求严格、有过逾期、配合度低、有跑路风险等

**审核**：
- 系统自动检测：辱骂、人身攻击、敏感词、广告
- 人工抽检：随机 10% 评价人工审核
- 客户申诉：被评价方可发起申诉

#### M4.3 上报审核流程

```
商家提交上报
     ↓
系统初审（24h 内）
  ├─ 证据完整性校验
  ├─ 黑产识别（同 IP 多账号上报、关联账号等）
  └─ 历史诚信度评分
     ↓
进入"待确认状态"（被举报方可见）
     ↓
通知被举报方（短信 + 邮件，7 天申诉期）
     ↓
  ┌─────────────┐
  │ 7 天内申诉？  │
  └──┬──────┬───┘
    是      否
     ↓      ↓
  人工调查   自动入库
     ↓      ↓
  最终裁定   公示
     ↓
  推送给曾交易该客户的商家
```

1. **货袋子原生 ERP**：内置集成，零配置

3. **轻量级**：浏览器插件，自动识别企业名称弹出信用卡片

**典型场景**：
```
商家 ERP 录入新客户 "上海XX建材"
   ↓
ERP 自动调用 货袋子 API
   ↓
1秒内返回：
   ├─ 信用等级：A（700分）
   ├─ 风险提示：⚠️ 在3家商家有逾期
   └─ 建议：建议预付款 50%，账期不超过15天
```

## 4. 核心业务规则

### 4.1 信用评分模型

```
综合信用分 = ROUND(
    付款行为分 × 0.35
  + 交易稳定分 × 0.20
  + 同行口碑分 × 0.20
  + 工商风险分 × 0.15
  + 行为风险分 × 0.10
)

【各维度计算逻辑】

付款行为分 = 100
  - (累计逾期天数 / 累计应付天数) × 100
  - 逾期次数 × 5
  - 当前未还款额 / 累计交易额 × 50
  ↓ 按该客户在所有商家的实际付款数据加权计算

交易稳定分 = MIN(100,
    交易商家数 × 5            // 最多20家封顶
  + 交易月份数 × 2            // 最多50月封顶
  + LOG10(累计交易额) × 10    // 规模因子
  - 行业平均偏离度 × 30
)

同行口碑分 = 评价星级均分 × 20 - 负面标签数 × 5

工商风险分 = 100
  - 失信被执行人 × 50
  - 被执行人 × 30
  - 经营异常 × 20
  - 行政处罚 × 10
  - 股权频繁变更 × 5

行为风险分 = 100
  - 询价取消率 × 50
  - 恶意压价次数 × 5
  - 客诉次数 × 10
  - 关联企业风险 × 30
```

### 4.2 信用等级与建议动作

| 等级 | 分数 | 颜色 | 建议商家动作 |
|------|------|------|------------|
| AAA | 900-1000 | 🟢 深绿 | 强烈推荐，可给最长账期 |
| AA | 800-899 | 🟢 绿 | 推荐，正常账期 |
| A | 700-799 | 🟡 黄绿 | 普通客户，标准账期 |
| B | 600-699 | 🟡 黄 | 谨慎，缩短账期 |
| C | 500-599 | 🟠 橙 | 高风险，建议预付款 50% |
| D | 0-499 | 🔴 红 | 黑名单，建议拒绝交易 |

### 4.3 黑名单触发规则（自动 + 人工）

**自动触发**：
- 法院失信被执行人 → 直接 D 级
- 在 ≥ 3 家商家有逾期 90 天以上未还款 → 自动 C 级
- 在 ≥ 5 家商家有累计 ¥50 万+ 欠款 → 自动 D 级
- 工商显示注销、吊销、列入异常 → 自动 D 级
- 关联企业出现严重风险 → 信用分扣减 100-300

**人工触发**：
- 商家上报且证据完整（≥ 2 项证据）→ 24h 内入"灰名单"（橙色预警）
- 申诉期（7 天）无回应 → 自动转黑名单
- 申诉成立 → 撤销

### 4.4 数据可信度优先级

```
ERP 自动同步数据  >  第三方权威 API  >  商家批量上报  >  商家单条上报  >  匿名提示
   高可信               中高可信             中可信              低可信         参考
```

冲突时按优先级取数。

### 4.5 数据脱敏规则

| 数据 | 对查询方可见 | 对被查询方可见 | 对外（公网） |
|------|------------|--------------|-------------|
| 客户名称 | ✓ | ✓ | ❌ |
| 信用分 | ✓ | ✓ | ❌ |
| 上报商家名 | "商家A、B" 脱敏 | 仅显示数量 | ❌ |
| 具体欠款金额 | ✓（仅汇总） | ✓ | ❌ |
| 评价内容 | ✓ | ✓（脱敏发件人） | ❌ |
| 法人手机/身份证 | ❌ | —— | ❌ |

## 5. 业务流程

### 5.1 主流程：商家查询客户信用

```
商家登录货袋子 App
        ↓
点击"信用查询" → 输入客户名称
        ↓
平台搜索匹配
        ↓
   ┌────────┴────────┐
 已有档案          无档案
   ↓                ↓
直接展示         调用工商 API
                 创建档案 + 展示
        ↓
扣减查询额度（前置校验余额）
        ↓
商家阅读报告 → 决策
        ↓
   ┌────────┴────────┐
  成交              拒绝
   ↓                ↓
登记交易（可选）   存档（可选）
        ↓
"加入关注"持续追踪
```

### 5.2 主流程：商家上报欠款

```
商家进入"我要上报"
        ↓
选择上报客户 → 填写表单 + 上传证据
        ↓
电子签名《信用上报承诺书》
        ↓
提交 → 系统初审（24h）
        ↓
通过 → 进入"待确认"（被举报方可见）
        ↓
推送被举报方（短信+邮件）→ 7 天申诉期
        ↓
   ┌────────┴────────┐
 无申诉          有申诉
   ↓                ↓
自动入库         人工调查
   ↓                ↓
推送同业         裁定
                  ↓
              入库 / 撤销
```

## 6. 非功能需求

### 6.1 性能

- 单次查询响应 ≤ 1.5 秒
- 批量查询 1000 条 ≤ 60 秒
- 系统可用性 99.9%
- 高峰期 QPS ≥ 500

### 6.2 安全

- 所有查询有详细审计日志
- 防爬虫：单 IP 限流 + 行为验证码
- 数据脱敏：报告水印、防截图（APP 端）
- API 鉴权：双向 SSL + Token + 签名

### 6.3 合规

- 仅采集 B 端企业数据，不涉及个人信用
- 用户协议明确数据用途
- 信息主体的"知情权 + 申诉权"
- 符合《数据安全法》《个人信息保护法》

### 6.4 兼容性

- 浏览器：Chrome、Edge、Safari、360（兼容钢贸老板常用浏览器）
- APP：iOS 12+、Android 8+
- ERP 集成：HTTP API、WebHook、SDK（Java/PHP/.NET）
