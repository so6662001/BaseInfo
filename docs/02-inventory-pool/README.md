# 方案二：滞销库存共享池（B2B 现货置换）

> **战略定位：解决商家最痛的资金占用问题，启动 B2B 撮合飞轮**

## 一、为什么是关键功能

钢贸商家仓库里普遍有 10-30% 的库存属于**滞销死货**：
- 特殊规格（非主流尺寸）
- 非常用材质
- 特定钢厂偏好（地方关系采购）
- 季节性产品

这些死货占用资金、占用仓位，砸手里几个月卖不掉。**而其他地区/其他商家可能正好缺这种货**。货袋子作为聚合 2000 家商家的平台，是天然的"现货置换中心"。

## 二、核心价值主张

| 视角 | 价值 |
|------|------|
| 卖方商家 | 死货变活钱，资金周转加快 |
| 买方商家 | 满足客户特殊需求，少跑腿 |
| 平台 | 启动 B2B 撮合 GMV，培养商家间交易习惯 |
